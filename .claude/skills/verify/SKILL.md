Run `./check.sh` from the project root. It needs network access and Google Chrome, so run it outside the Bash sandbox.
`PASS` means 20+ CEX rows by default and 30+ more with DEX ticked, the settings panel and output are really hidden on load (computed style), the matrix loaded (20+ exchanges), select-all ticked every cell, and the generated lists are well-formed `EXCHANGE:SYMBOL` with no duplicates, none over 1000 symbols, with a zip link. Anything else is a failure: report the printed reason.
